# Project

This is a modern web application built with a powerful tech stack.

## Tech Stack

This project uses the following key technologies:

- **TanStack Start**: A full-stack framework for React applications.
- **React**: For building the user interface.
- **Tailwind CSS**: For utility-first styling.
- **Supabase**: For backend services like authentication and database.

## Setup Instructions

To get started with this project, follow these steps:

1. **Install dependencies:**

   ```bash
   npm install
   ```

2. **Run the development server:**

   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## Linting and Formatting

- To check for linting errors, run `npm run lint`.
- To format the code, run `npm run format`.
